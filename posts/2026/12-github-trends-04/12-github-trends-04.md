# Тренди GitHub #04: локальний AI, автопілот для авто, OSINT-інструменти

Зібрав для вас свіженьки проєкти з трендів GitHub за минулий тиждень 🤗

1. 🎯 [Strapi](https://github.com/strapi/strapi) - опен-сорс headless CMS, з можливістю хостити самому або в хмарі. Пробував використовувати, загалом крута штука. 

2. ✏️ [Excalidraw](https://github.com/excalidraw/excalidraw) - віртуальна дошка для ескізів рукописних діаграм. Картинка для цього поста зроблена за допомогою саме нього.

3. 🤖 [LocalAI](https://github.com/mudler/LocalAI) - open-source AI-рушій для запуску будь-яких моделей штучного інтелекту (LLMs, зір, голос, зображення, відео тощо), причому на будь-якому обладнанні, GPU не потрібен.

4. 🛡️ [Anubis](https://github.com/TecharoHQ/anubis) - утиліта AI веб-файрвола, яка захищає ваші ресурси від ботів.

5. 🚗 [OpenPilot](https://github.com/commaai/openpilot) - вихідний код адаптивного круїз-контролю від компанії CommaAI.

6. 🎁 [Pake](https://github.com/tw93/Pake) - перетворіть будь-яку веб-сторінку на нативний застосунок однією командою.

7. 🕵️ [OSINT Stuff Tool Collection](https://github.com/cipher387/osint_stuff_tool_collection) - колекція кількасот онлайн-інструментів для OSINT розслідувань.
