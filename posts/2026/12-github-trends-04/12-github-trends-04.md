# Тренди GitHub #4: локальний запуска AI, автопілот для авто, OSINT інструменти

1. 🎯 [Strapi](https://github.com/strapi/strapi) - опен-сорс headless CMS, з можливістю хостити самому або в хмарі. Пробував використовувати, загалом крута штука. З плюсів, те що це зрілий проєкт і можна самому хостити і ні від кого не залежати.

2. ✏️ [Excalidraw](https://github.com/excalidraw/excalidraw) - віртуальна дошка для ескізів рукописних діаграм. Як виявилося то я візуальна людина, дуже подобається як виглядає все, можна вбудувати в ваш продукт, класне рішення.

3. 🤖 [LocalAI](https://github.com/mudler/LocalAI) - open-source AI рушій для запуску будь-яких моделей штучного інтелекту (LLMs, зір, голос, зображення, відео тощо) причому на будь-якому обладнанні, GPU не потрібен. Не шарю поки за AI, але виглядає добре.

4. 🛡️ [Anubis](https://github.com/TecharoHQ/anubis) - утиліта AI веб-файрвола, яка захищає ваші ресурси від ботів. Як я зрозумів з опису то такий Cloudflare від ботів на максималках, щоб взагалі ніхто не пройшов.

5. 🚗 [OpenPilot](https://github.com/commaai/openpilot) - вихідний код адаптивного круіз-контролю від компанії CommaAI. Це не найкорисніший з проєктів тут, але ви просто вдумайтесь: це фактично вихідний код автопілоту для вашого авто, в які цікаві часи ми живемо.

6. 🎁 [Pake](https://github.com/tw93/Pake) - перетворіть будь-яку веб-сторінку на нативний застосутнок однією командою. Це така обгортка на Tauri, який є альтернативою Electron.

7. 🕵️ [OSINT Stuff Tool Collection](https://github.com/cipher387/osint_stuff_tool_collection) - колекція кількасот онлайн-інструментів для OSINT розслідувань.
